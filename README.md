The Last Vault is a top-down stealth heist game: thief Mara Voss crosses the Meridian Museum gallery past patrolling guards and sweeping security cameras, pockets the gold bars, the jewel case and the vault itself, then slips out the service exit before the alarm fills.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — move with WASD or arrow keys, hold E at the vault to crack it, press J to jam the cameras, click to toss a noisemaker coin.
